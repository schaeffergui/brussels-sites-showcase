# Projetos demonstrativos de Bruxelas

Projeto estático com o Mostruário e cinco demonstrações navegáveis.

## Estrutura

- `portfolio/`: Mostruário e estudos de caso.
- `kanel-landing/`, `le-petit-lion/`, `el-sabor/`, `keufte-ixelles/`, `le-petit-liberty/`: demonstrações.

## Direitos e escopo

Conceitos independentes, sem encomenda ou vínculo com os estabelecimentos. Dados de endereço, horário e contato são demonstrativos e devem ser confirmados antes de uso comercial. Fotos de visitantes/Google Maps e capturas/vídeos que as continham foram mantidos fora desta cópia; foram substituídos por placeholders gráficos que não representam imagens reais dos locais. Os vídeos locais foram omitidos. Kanel conserva imagens do Wikimedia Commons com os créditos e licenças da página. Fontes licenciadas conforme os arquivos de licença dos projetos.
